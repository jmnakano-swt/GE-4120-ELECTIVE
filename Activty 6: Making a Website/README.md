## 𓍢ִ໋🌷 01 — Introduction

For this activity, I used **Replit AI** to create a website for a fictional beauty brand called **Mori Beauty**.

Mori Beauty is a beauty and cosmetics website designed to showcase makeup products, skincare essentials, and beauty collections. The goal was to create an attractive, colorful, and user-friendly website that reflects a modern and feminine beauty brand.

I used AI-assisted website development to turn my ideas into an actual website without having to write every line of code manually.

## 🖥️ 04 — Development Using Replit AI

I used **Replit AI** as my website development assistant. Instead of coding everything from scratch, I provided a prompt describing the website I wanted to create.

### Development Process

**01 — Planning**

I decided on the website concept, brand identity, color palette, and sections.

**02 — Prompting**

I described Mori Beauty to Replit AI and explained the features, layout, and aesthetic I wanted.

**03 — AI Generation**

Replit AI helped generate the website structure, design, and code based on my instructions.

**04 — Customization**

I reviewed the generated website and made adjustments to improve its appearance and functionality.

**05 — Final Output**

I previewed the finished website and checked its layout, design, and user experience.
